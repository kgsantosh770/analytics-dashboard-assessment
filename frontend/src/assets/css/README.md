# 🛍️ Nearbuy

Nearbuy is a modern ecommerce web application that helps users discover, browse, and purchase products from nearby and online sellers — all in one place. Built with a sleek, responsive interface, Nearbuy delivers a seamless shopping experience across devices.

---

## 🚀 Features

- 🔍 **Product Search & Filter**  
  Easily find products using keywords, categories, and price filters.

- 🛒 **Shopping Cart & Checkout**  
  Add items to cart, manage quantities, and place orders with ease.

- 👤 **User Authentication**  
  Sign up, log in, and manage your account securely.

- 🧾 **Order History**  
  Track all your past orders and their statuses.

- 💬 **Product Reviews & Ratings**  
  View and leave feedback for products.

- 📱 **Responsive Design**  
  Fully optimized for desktop, tablet, and mobile screens.
